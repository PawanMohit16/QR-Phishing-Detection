How the score works

Each indicator adds points (shortened URL 20, untrusted domain 20, credential request 18, urgency words 7, call-to-action 6 …), capped at 100. 0–21 legitimate · 22–49 suspicious · 50+ high-risk.

OCR and QR decoding run in your browser. The text is sent to a Python API that applies the rules and a TF-IDF + logistic-regression model trained on synthetic data. Domains are fictional.
